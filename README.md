<details>
<summary><b>🔗 Webhook Delivery Engine</b> &nbsp;—&nbsp; Production-grade async event fan-out system</summary>

<br/>

A Spring Boot service that delivers HTTP POST webhooks to registered subscribers with per-attempt tracking, retry logic, and full audit persistence. Designed around a clean 4-table schema and deployed to AWS EC2 as a Docker Compose stack.

<div align="center">

| Attribute | Detail |
|-----------|--------|
| **Stack** | Java 17, Spring Boot, Spring Scheduler, JPA, MySQL, Docker Compose, AWS EC2 |
| **Architecture** | Async fan-out, event-subscriber model, per-attempt state machine |
| **Retry Logic** | Exponential backoff — 3 attempts at 30s / 60s / 120s intervals |
| **Persistence** | SQL-persisted delivery audit log with attempt timestamps and status codes |
| **Deployment** | Containerized via Docker Compose, deployed to AWS EC2 Ubuntu 24 (free tier) |
| **Security** | Endpoint-level subscriber validation, isolated retry queue per event |
| **Repository** | [github.com/mohammedaadils/webhook-engine](https://github.com/mohammedaadils/webhook-engine) |

</div>

This project was built to demonstrate production-style backend engineering at the fresher level — going beyond CRUD to implement observable, fault-tolerant event delivery with real deployment. The retry scheduler, audit schema, and Docker setup reflect patterns used in real webhook infrastructure at scale.

</details>
