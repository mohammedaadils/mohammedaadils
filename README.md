## ◈ Featured Projects

<details>
<summary><b>🔗 Webhook Delivery Engine</b> &nbsp;—&nbsp; Production-grade async event fan-out system</summary>

<br/>

A Spring Boot service that delivers HTTP POST webhooks to registered subscribers with per-attempt tracking, retry logic, and full audit persistence. Designed around a clean 4-table schema and deployed to AWS EC2 as a Docker Compose stack.

<div align="center">

| Attribute | Detail |
|-----------|--------|
| **Stack** | Java 17, Spring Boot, Spring Scheduler, JPA, MySQL, Docker Compose, AWS EC2 |
| **Architecture** | Async fan-out, event-subscriber model, per-attempt state machine |
| **Retry Logic** | Exponential backoff — 3 attempts at 30s / 60s / 120s intervals |
| **Persistence** | SQL-persisted delivery audit log with attempt timestamps and status codes |
| **Deployment** | Containerized via Docker Compose, live on AWS EC2 Ubuntu 24 (free tier) |
| **Security** | Endpoint-level subscriber validation, isolated retry queue per event |
| **Repository** | [github.com/mohammedaadils/webhook-engine](https://github.com/mohammedaadils/webhook-engine) |

</div>

This project was built to demonstrate production-style backend engineering at the fresher level — going beyond CRUD to implement observable, fault-tolerant event delivery with real deployment. The retry scheduler, audit schema, and Docker setup reflect patterns used in real webhook infrastructure at scale.

</details>

<details>
<summary><b>🧬 DeepMorph — AI DNA Mutation Prediction</b> &nbsp;—&nbsp; Multi-task genomic deep learning pipeline</summary>

<br/>

A hybrid CNN-LSTM system trained on one-hot encoded DNA sequences to simultaneously predict mutation status, gene classification, and clinical significance — three output tasks from a single model. Wrapped in a FastAPI inference service for REST-based genomic analysis.

<div align="center">

| Attribute | Detail |
|-----------|--------|
| **Stack** | Python, PyTorch, CNN-LSTM, FastAPI, NumPy, Pandas |
| **Architecture** | Hybrid multi-task CNN-LSTM with shared encoder and task-specific heads |
| **Input** | One-hot encoded DNA sequence tensors |
| **Output Tasks** | Mutation status · Gene classification · Clinical significance (3 simultaneous) |
| **Performance** | ~50% reduction in manual classification effort vs baseline |
| **API** | FastAPI REST interface with structured JSON output and risk-level labels |
| **Repository** | [github.com/mohammedaadils/DeepMorph--AI-DNA-Mutation-Prediction](https://github.com/mohammedaadils/DeepMorph--AI-DNA-Mutation-Prediction) |

</div>

DeepMorph tackles a real bioinformatics problem: predicting clinically relevant genomic outcomes from raw sequence data. The multi-task design is architecturally deliberate — shared representations reduce overfitting across low-resource tasks, and the FastAPI layer makes the model immediately usable as a service.

</details>

| **Impact** | ~65% reduction in manual test authoring time in internal trials |
| **Coverage** | Generates test cases across 3 API endpoint types (GET, POST, edge cases) |

This project started as internship tooling and ended as a published research contribution. The core insight — that LLMs can generate structurally valid Postman collections from natural language API descriptions — has practical implications for QA automation at scale.
